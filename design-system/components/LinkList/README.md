# LinkList

Les liens utiles, groupés par thème : un nom de site, une ligne pour dire ce qu'il est.

## Balisage

`.links` (deux colonnes, une sous 900 px) > `div` > `h4` (`label` en capitales, `ink2`) + `ul` > `li` > `a` (nom + icône lien-externe 16 px, nouvel onglet) + `span` (description `caption`, `ink2`).

## Thèmes

Sociétés savantes (SNFCP, SNFGE, SFHGL ex-CREGG) ; Dépistage ; Incontinence fécale ; Maladie de Verneuil ; Santé sexuelle et IST.

## Règles

- Le nom du site est le lien ; la description n'est pas cliquable.
- Une description quand le nom ne suffit pas (un sigle), sinon rien.
- Pas de lien sans adresse : un lien du site actuel qui n'en a pas attend d'être fourni.
