# KeyFacts

Les points clés d'un traitement, en petites cartes : ce qu'un patient veut savoir d'un coup d'œil.

## Balisage

`dl.keys[aria-label="… en bref"]` > `div` > `dt` (`label`, `ink2`) + `dd` (`key-value`, `navy`). Quatre colonnes, deux sous 900 px.

## Règles

- Placées après le texte explicatif, dans la même sous-rubrique `.sub`.
- Quatre points au plus, chacun en quelques mots tirés du texte du cabinet : Durée « 15 à 45 minutes », Anesthésie « Le plus souvent générale », Arrêt de travail « Quelques jours », Soins infirmiers « Généralement aucun ».
- Rien qui ne soit écrit dans le texte au-dessus : les points clés résument, ils n'ajoutent pas.
