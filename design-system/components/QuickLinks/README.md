# QuickLinks

Les trois raccourcis de verre sous le hero de l'accueil, vers les besoins les plus pressants.

## Balisage

`ul.quick[aria-label="Accès rapides"]` > `li` > `a.glass` : icône 22 px, libellé `item`, flèche 18 px. Le raccourci d'urgence prend `is-urgent` (icône et contour au survol `urgent`).

## Règles

- Trois raccourcis, toujours les mêmes : En cas d'urgence, Votre intervention, Venir au cabinet. Pas de raccourci vers la prise de rendez-vous.
- Contour `panel-line`, `brand` au survol ; ombre `shadow-chip` ; arrondi `radius-m`.
- Une colonne sous 900 px.
