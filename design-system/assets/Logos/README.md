# Logos

Le trèfle du cabinet : quatre feuilles en trois couches de bleu (`logo-1` à l'extérieur, `logo-2` au milieu, `logo-3` au centre). Polychrome : ne le recolorez pas, ne le déformez pas. Il n'existe pas de version avec le nom intégré : le nom se compose toujours en texte, en `brand-name`, à côté du trèfle.

- `logo-trefle-plat.svg` — La version du site, en aplats. Insérez-la en SVG en ligne : 40 × 41 px dans l'en-tête, 44 × 46 px dans le pied de page, 24 px dans les vignettes de livret. C'est aussi la source du trèfle 3D d'arrière-plan et du filigrane de secours. Taille minimale : 24 px.
- `logo-trefle-blanc.svg` — La version blanche (encre `#ffffff`), pour un fond photo ou un fond plus foncé que `brand` quand les bleus ne ressortent pas. Elle paraît vide sur fond clair.
- `logo-trefle.svg` — La version d'origine du site actuel, avec ombres internes. Gardée pour l'impression et les grands formats ; sur le nouveau site, préférez la version plate.
